Quiero agregar dentro de la plataforma existente “gestión” un dashboard ejecutivo y financiero para operación de barcos, similar a una vista tipo Uber / Airbnb Charter. No quiero una app nueva. Debe integrarse dentro del sistema actual con el mismo estilo visual.

OBJETIVO
Crear una pantalla única donde pueda ver de forma rápida y clara el rendimiento del negocio y de cada embarcación, incluyendo:
- ingresos por día
- ocupación
- horas vendidas
- rentabilidad por barco
- bookings futuros
- gastos por barco
- utilidad por barco

La prioridad es que sea una vista simple, rápida, muy útil y bien conectada con los datos que ya existen en el sistema.

REGLAS
- no crear aplicación separada
- integrarlo dentro de “gestión”
- mantener la UI actual
- no usar librerías pesadas
- optimizar para bajo consumo en Replit
- reutilizar datos ya existentes del sistema
- construir primero un MVP funcional y luego mejoras visuales menores
- no duplicar lógica ni tablas si ya existen

8. RENTABILIDAD POR BARCO
==================================================

- Barco
- Ingresos
- Horas vendidas
- Bookings
- Gastos
- Capitán
- Stew
- Utilidad
- Margen %

FÓRMULA
Utilidad = ingresos - gastos - pagos crew

Donde:
- ingresos = booking revenue del barco
- gastos = gastos contables con boat_id
- capitán = pagos de captain vinculados al barco
- stew = pagos de stew vinculados al barco

Margen %:
- utilidad / ingresos * 100
- si ingresos = 0, mostrar 0 o vacío
