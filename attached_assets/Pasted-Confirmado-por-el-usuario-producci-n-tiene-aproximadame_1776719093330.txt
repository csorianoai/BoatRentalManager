## PASO 5 — Corrección propuesta

Escribe la query corregida del endpoint de Conciliación siguiendo esta estructura:

```sql
SELECT 
  b.id AS booking_id,
  b.booking_date,
  b.customer_name,
  b.boat_type AS barco,
  b.platform AS canal,
  b.total_amount AS facturado,
  COALESCE(SUM(t.amount), 0) AS cobrado,
  COALESCE(SUM(d.amount), 0) AS depositado,
  b.total_amount - COALESCE(SUM(t.amount), 0) AS gap_facturado_cobrado,
  COALESCE(SUM(t.amount), 0) - COALESCE(SUM(d.amount), 0) AS gap_cobrado_depositado,
  CASE 
    WHEN COALESCE(SUM(t.amount), 0) = 0 THEN 'Sin cobro'
    WHEN COALESCE(SUM(t.amount), 0) < b.total_amount THEN 'Cobro parcial'
    WHEN COALESCE(SUM(d.amount), 0) = 0 THEN 'Cobrado sin depósito'
    WHEN COALESCE(SUM(d.amount), 0) < COALESCE(SUM(t.amount), 0) THEN 'Depósito parcial'
    ELSE 'Conciliado'
  END AS status_conciliacion
FROM bookings b
LEFT JOIN transactions t ON t.booking_id = b.id
LEFT JOIN deposits d ON d.transaction_id = t.id  -- ajusta FK según schema real
WHERE b.booking_date >= $1 AND b.booking_date <= $2
GROUP BY b.id, b.booking_date, b.customer_name, b.boat_type, b.platform, b.total_amount
ORDER BY b.booking_date DESC;
```

Adapta nombres de columnas a tu schema real. El principio es inviolable: **bookings es la tabla principal, el resto se suma vía LEFT JOIN**.
