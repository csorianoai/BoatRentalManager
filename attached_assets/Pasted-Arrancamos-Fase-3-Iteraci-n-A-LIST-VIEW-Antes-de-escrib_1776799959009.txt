## ALCANCE LIST VIEW (Fase 3A)

### 1. Vista List como 4ta pestaña del Fleet Operations Center

Tabs del sistema:
- Timeline (default, ya existe)
- Weekly (placeholder — "Próximamente")
- Month (placeholder — "Próximamente")  
- List (nueva, funcional)

Al hacer click en List, carga la vista de tabla densa con todos los bookings del rango temporal activo (respetando filtros globales del Fleet Ops Center).

### 2. Tabla densa estilo Airbnb Host Reservations

Columnas en este orden (todas sortables):
1. Checkbox (para bulk actions)
2. Fecha servicio (booking_date formato "Apr 25, 2026")
3. Hora (start_time)
4. Duración (duration_hours con unidad "h")
5. Booking ID (ref corta, con botón copiar ID)
6. Cliente (customer_name con teléfono en hover)
7. Barco (COALESCE boat_type con color dot del barco)
8. Paquete/Tipo si existe
9. Guests (count si existe, sino "—")
10. Capitán (captain_name con badge ⚠ si falta)
11. Stew (stew_name)
12. Canal (platform con chip de color)
13. Status (chip de color según payment_status/booking_status)
14. Pagado (SUM transactions por booking si existe, sino "—")
15. Total (total_amount mono tabular)
16. Acciones (3-dot menu con: Ver drawer, Asignar capitán, Marcar pagado, Cancelar, Duplicar)

### 3. Densidad configurable

Toggle arriba de la tabla con 3 modos:
- **Compact** (32px row) — para ver 30+ bookings en pantalla
- **Medium** (40px row) — default
- **Comfortable** (56px row) — para pantallas pequeñas

Persistir preferencia en localStorage como "foc-list-density".

### 4. Sort y filtros

- Click en header de columna → sort asc/desc con chevron visual
- Sort persistente durante la sesión
- Filtros globales del Fleet Ops Center aplican a List (rango fechas, barcos, canales)
- Filtro adicional específico de List: buscador de texto que busca en customer_name, booking_id, captain_name simultáneamente

### 5. Bulk Actions

Al seleccionar 1+ bookings via checkbox, aparece barra de acciones flotante en parte inferior:
- "Asignar capitán a N reservas" → modal con picker de capitán
- "Marcar N como pagadas" → modal confirmación
- "Confirmar N reservas" → modal confirmación
- "Exportar N como CSV" → descarga archivo
- "Cancelar N reservas" → modal con razón obligatoria

Regla: cada bulk action genera entries en el log de actividad de cada booking afectado.

### 6. Exportación

Dos botones arriba de la tabla:
- **Export CSV** — descarga todos los bookings del filtro actual (no solo los seleccionados)
- **Export PDF** — genera PDF con tabla + header con logo/fecha/rango

Formato CSV debe incluir TODAS las columnas visibles + columnas adicionales útiles:
- customer_phone
- customer_email  
- service_date
- notes
