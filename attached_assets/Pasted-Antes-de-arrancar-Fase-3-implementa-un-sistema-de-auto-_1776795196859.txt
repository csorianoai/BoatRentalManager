### 2.2 Suite de validación — Fleet Ops Center

Implementa cada una como test de Playwright independiente. Cada test retorna PASS / FAIL / WARN con detalle.

**Infraestructura (8 tests):**

- I-01: ¿El HTML de producción tiene BUILD_TS del último deploy?
- I-02: ¿El archivo fleet-ops.js se carga sin error 404?
- I-03: ¿El archivo fleet-ops.js tiene más de 40KB de tamaño? (proxy de "no es el archivo viejo")
- I-04: ¿Los endpoints /api/fleet/{timeline,kpis,alerts,today-strip} responden 200 en <500ms?
- I-05: ¿El response de /api/fleet/timeline tiene estructura JSON esperada? (campos meta, data, errors)
- I-06: ¿La página no muestra errores en console al cargar? (capturar errors de window)
- I-07: ¿No hay referencias huérfanas a funciones viejas (renderCalendar, renderCalendarGrid)?
- I-08: ¿El CSS del drawer (foc-drawer) está cargado correctamente?

**Data integrity (6 tests):**

- D-01: ¿El KPI de bookings coincide con COUNT(*) directo a bookings en el mismo rango?
- D-02: ¿El KPI de revenue coincide con SUM(total_amount) directo?
- D-03: ¿Los barcos renderizados coinciden con los que tienen bookings + los is_active=true de fleet_config?
- D-04: ¿Los nombres de barco son comerciales (CRANCHI, SEARAY 500) y NO son IDs técnicos (boat_XXXX)?
- D-05: ¿La utilización calculada está en rango razonable (0-100%) y no es 0% falso?
- D-06: ¿El Today Strip refleja lo que devuelve COUNT(*) de bookings WHERE booking_date = CURRENT_DATE?

**UI behavior (10 tests):**

- U-01: Click en un bloque de booking → se abre elemento con clase foc-drawer-open
- U-02: Drawer tiene 4 secciones detectables por texto o ID
- U-03: Drawer tiene 8 botones de acción
- U-04: Drawer muestra chip de canal con color (tiene style inline o clase de color)
- U-05: Drawer muestra chip de payment_status con color
- U-06: Botón "Copiar ID" existe y tiene handler
- U-07: Esc cierra el drawer (la clase foc-drawer-open desaparece)
- U-08: Panel de alertas visible en la página (#foc-alerts-panel existe y tiene altura >0)
- U-09: Today Command Strip visible en la página (#foc-today-strip existe y tiene altura >0)
- U-10: Navegación temporal (flechas anterior/siguiente) cambia el rango sin reload de página

**Integrity check (4 tests):**

- C-01: Número de bookings en dev vs prod. Si hay discrepancia >50%, WARN.
- C-02: Número de barcos en dev vs prod. Si hay discrepancia, WARN.
- C-03: Al ejecutar tests en prod, confirmar que el BUILD_TS renderizado es el último.
- C-04: Ejecutar grep en el repo de funciones obsoletas que deberían estar eliminadas.
