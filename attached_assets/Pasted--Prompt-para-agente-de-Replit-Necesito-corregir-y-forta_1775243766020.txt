# Prompt para agente de Replit

Necesito corregir y fortalecer el funcionamiento del **dashboard principal**, el **calendario de reservas** y la **sincronización de estadísticas** en la plataforma.

## Objetivo general
El dashboard principal debe reaccionar correctamente a los filtros de fecha y plataforma, mostrar estadísticas reales, y consolidar en tiempo real todas las reservas creadas en el sistema, tanto automáticas como manuales.

Actualmente, cuando selecciono una **plataforma** o un **rango de fechas**, el dashboard **no actualiza nada**. Eso debe corregirse.

Además, todas las reservas que voy ingresando, ya sean:
- automáticas,
- manuales desde el calendario,
- o provenientes de integraciones/plataformas,

deben reflejarse correctamente en el **resumen del dashboard principal**.

# 1. Corregir el dashboard principal para que responda a filtros

## Problema actual
Cuando selecciono una plataforma o un rango de fechas:
- el dashboard no se mueve,
- no actualiza estadísticas,
- no cambia totales,
- no cambia reservas,
- no cambia métricas,
- y no refleja los datos históricos, presentes o futuros según el filtro.

## Requerimiento
Debes hacer que el dashboard principal responda correctamente a los filtros de:

### Filtros mínimos
- **Plataforma / broker / fuente**
- **Rango de fechas**
- **Mes**
- **Semana**
- **Día**
- **Pasado / presente / futuro** si existe esa lógica o si puede inferirse por fecha

## Comportamiento esperado
Cuando seleccione:
- una plataforma específica,
- una semana,
- un mes,
- o cualquier rango de fechas,

el dashboard debe recalcular y actualizar inmediatamente:
- cantidad de bookings,
- ingresos,
- reservas por plataforma,
- reservas por periodo,
- reservas por barco,
- reservas por capitán si aplica,
- y cualquier estadística principal visible en el dashboard.

# 3. Sincronización entre calendario y dashboard
## Requerimiento
Cada vez que se cree, edite, elimine o cancele una reserva en el calendario, el dashboard debe reflejar ese cambio correctamente.

### Esto aplica para:
- reservas manuales creadas en calendario,
- reservas automáticas,
- reservas importadas o sincronizadas,
- cambios de precio,
- cambios de fecha,
- cambios de broker/plataforma,
- cambios de barco,
- cambios de estado.

## Comportamiento esperado
Si agrego una reserva manual:
- debe aparecer en el calendario,
- y también debe impactar los KPIs y resúmenes del dashboard.

Si modifico una reserva:
- debe recalcularse el resumen.

Si filtro por plataforma o por fecha:
- debe incluir esas reservas correctamente.

- **Presente:** reservas y actividad actual

### Si se filtra por fecha:
Debe devolver solo los datos dentro del rango seleccionado.

### Si se filtra por plataforma y fecha al mismo tiempo:
Debe combinar ambos filtros correctamente.

Ejemplo:
- Plataforma = Boatsetter
- Fecha = marzo 2026

Resultado esperado:
- solo bookings de Boatsetter dentro de marzo 2026
- revenue solo de ese subconjunto
- KPIs y gráficos actualizados con esa data
