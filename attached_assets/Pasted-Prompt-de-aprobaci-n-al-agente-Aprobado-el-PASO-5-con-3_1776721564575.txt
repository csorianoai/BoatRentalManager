## AJUSTE 2 — Agregar columnas útiles para operación real

Añadir a la query:

- `b.booking_reference` (o el ID legible del booking, no el UUID) — alias `ref`
- `b.service_date` si existe en schema — para cuando booking_date ≠ service_date  
- Columna calculada `gap_pct` = `gap / facturado * 100`

Query final propuesta:

```sql
SELECT 
  b.id                                                  AS booking_id,
  b.booking_reference                                   AS ref,
  b.booking_date,
  b.service_date,
  b.customer_name,
  COALESCE(b.boat_type, b.boat_id, 'Sin asignar')       AS barco,
  COALESCE(b.platform, 'Directo')                       AS canal,
  b.total_amount::numeric                               AS facturado,
  COALESCE(SUM(t.amount), 0)                            AS cobrado,
  NULL::numeric                                         AS depositado,
  b.total_amount::numeric - COALESCE(SUM(t.amount), 0)  AS gap,
  CASE 
    WHEN b.total_amount = 0 THEN 0
    ELSE ROUND(((b.total_amount::numeric - COALESCE(SUM(t.amount), 0)) / b.total_amount * 100), 2)
  END                                                   AS gap_pct,
  CASE 
    WHEN COALESCE(SUM(t.amount), 0) = 0              THEN 'Sin cobro'
    WHEN COALESCE(SUM(t.amount), 0) < b.total_amount THEN 'Cobro parcial'
    ELSE 'Conciliado'
  END                                                   AS status_conciliacion
FROM bookings b
LEFT JOIN transactions t ON t.booking_id = b.id
WHERE b.booking_date >= $1
  AND b.booking_date <= $2
  AND b.status != 'cancelled'
GROUP BY b.id, b.booking_reference, b.booking_date, b.service_date,
         b.customer_name, b.boat_type, b.boat_id, b.platform, b.total_amount
ORDER BY b.booking_date DESC;
```

Si `booking_reference` o `service_date` no existen en el schema, usa NULL y reporta qué campos faltan.

### Diagnóstico adicional obligatorio antes de PASO 6

Ejecuta SOLO sobre producción:

```sql
-- T1: Total transactions en prod
SELECT COUNT(*) AS total_trans FROM transactions;

-- T2: Cobertura de booking_id en transactions PROD
SELECT 
  COUNT(*) AS total,
  COUNT(booking_id) AS con_booking_id,
  ROUND(100.0 * COUNT(booking_id) / NULLIF(COUNT(*), 0), 2) AS pct_vinculadas,
  COUNT(*) - COUNT(booking_id) AS sin_vincular
FROM transactions;

-- T3: Muestra de transactions sin booking_id para ver si hay pistas de vinculación
SELECT id, amount, transaction_date, description, payment_method, 
       customer_name, reference_number
FROM transactions 
WHERE booking_id IS NULL 
ORDER BY transaction_date DESC 
LIMIT 10;

-- T4: Intentar matching heurístico por fecha + monto
SELECT COUNT(*) AS potentially_matchable
FROM transactions t
JOIN bookings b 
  ON ABS(t.amount - b.total_amount) < 1
  AND DATE(t.transaction_date) BETWEEN b.booking_date::date - INTERVAL '7 days' 
                                    AND b.booking_date::date + INTERVAL '7 days'
WHERE t.booking_id IS NULL;
```
