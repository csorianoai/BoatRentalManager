FASE 3 — NUEVO ENDPOINT (CRÍTICO)
--------------------------------------------------

Body:
{
  "booking_id": string,
  "amount": number,
  "date": date,
  "notes": string
}

Lógica:

1. VALIDAR booking existe
2. INSERT en transactions:

   Dr 1015 (Cash Clearing)
   Cr booking_receivable o deferred_account (según corresponda)

3. Marcar booking:
   payment_status = 'partial' o 'paid'

4. Guardar referencia:
   reference_type = 'booking'
   reference_id = booking_id
