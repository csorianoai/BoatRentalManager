# 1. Corregir extracción real de datos del dashboard

- **2 reservas futuras de GetMyBoat**
- **1 reserva pasada de GetMyBoat**

Estas reservas deben reflejarse correctamente en el dashboard.

## Revisar posibles causas
Debes auditar y corregir cualquiera de estos problemas:

- queries incorrectas
- filtros de fecha mal aplicados
- filtros de plataforma mal aplicados
- joins rotos
- reservas guardadas en una tabla pero no consultadas por el dashboard
- reservas manuales vs automáticas tratadas por separado
- problemas con estados de reserva
- problemas con fechas UTC/local
- problemas con parseo de fechas
- reservas futuras excluidas por error
- reservas pasadas excluidas por error
- datos hardcodeados
- frontend que no refresca
- backend que no devuelve datos
- hooks o stores mal conectados
- cache o memoization impidiendo actualización
- errores silenciosos en consola o API
- agrupaciones por plataforma que fallan si falta algún campo
- reservas sin campos opcionales que rompen el resumen
