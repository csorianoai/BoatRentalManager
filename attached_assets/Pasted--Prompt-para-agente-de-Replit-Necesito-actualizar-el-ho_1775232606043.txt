# Prompt para agente de Replit

Necesito actualizar el home y el flujo de reservas para que el cliente pueda elegir primero la cantidad de horas y que el sistema actualice automáticamente los precios de cada barco según el día seleccionado.

## Requerimientos
1. Agrega en el home un selector de duración con:
   - 2h
   - 3h
   - 4h
   - 5h
   - 6h

2. Cuando el usuario elija una duración, deben mostrarse los precios correctos por barco.

3. Cuando el usuario seleccione una fecha, el sistema debe detectar:
   - **Monday - Thursday & Sunday**
   - **Friday & Saturday**

4. Según eso, debe aplicar el precio correcto.

5. Para la opción de **2 horas**, usar estos precios:
   - **Sundancer 50'** → $550
   - **Cranchi 50'** → $650
   - **Viking 50'** → $650

6. Si para 2 horas un barco no tiene tarifa definida, no inventes precio. En ese caso:
   - no mostrar esa opción para ese barco, o
   - mostrar claramente que no está disponible para 2 horas,
   según la UX más consistente con la app actual.

7. La actualización del precio debe ser inmediata, sin recargar la página.

8. La selección de horas y fecha debe mantenerse al navegar a resultados o al detalle del barco.

9. Centraliza la lógica de precios en una estructura mantenible, no hardcodeada en múltiples componentes.

10. Mantén consistencia visual con el sistema actual.

## Lógica esperada
- Si el cliente elige **2 horas**, el sistema debe traer de inmediato las embarcaciones que sí tienen tarifa para 2 horas y mostrar el precio correcto.
- Si el cliente cambia a 3h, 4h, 5h o 6h, recalcular automáticamente.
- Si el cliente selecciona viernes o sábado, usar tarifa de fin de semana.
- Si selecciona domingo, lunes, martes, miércoles o jueves, usar tarifa weekday.
- La lógica debe aplicarse en home, resultados y detalle del barco.
