Quiero mejorar el sistema existente “gestión”. No quiero una app nueva.

OBJETIVO
Crear un sistema básico de activos (inventario/equipos) para registrar bienes de la empresa como alfombras flotantes, radios, accesorios de barcos y otros equipos.

Estos elementos NO deben registrarse como gasto ni como ingreso, sino como activos.

==================================================
1. CREAR CUENTAS CONTABLES
==================================================

Agregar en el plan de cuentas:

ACTIVOS (Assets):
- Equipment
- Marine Equipment
- Inventory Assets

PASIVOS (si aplica):
- Accounts Payable

GASTOS (para uso futuro):
- Depreciation Expense

==================================================
2. NUEVO MÓDULO: ACTIVOS
==================================================

Crear una sección dentro de “gestión” llamada:
- Activos
o
- Inventario / Equipos

==================================================
3. REGISTRO DE ACTIVOS
==================================================

Permitir crear activos con los siguientes campos:

- nombre del activo
- categoría:
  - equipo
  - inventario
  - accesorio
  - marina
- descripción
- costo de compra
- fecha de compra
- proveedor opcional
- barco asignado opcional
- cantidad
- ubicación opcional
- estado:
  - activo
  - en uso
  - en mantenimiento
  - dañado
  - fuera de servicio
- notas

==================================================
4. LÓGICA CONTABLE
==================================================

Cuando se registra un activo:

SI se paga en efectivo:
- Debit: Equipment / Inventory Assets
- Credit: Cash / Banco

SI se compra a crédito:
- Debit: Equipment / Inventory Assets
- Credit: Accounts Payable

IMPORTANTE:
- NO registrar como gasto directo
- NO afectar ingresos

==================================================
5. ASIGNACIÓN A BARCOS
==================================================

Permitir asignar activos a un barco específico:

- boat_id
- boat_name

OBJETIVO
Poder saber qué activos tiene cada embarcación:
- radios por barco
- alfombras por barco
- equipos por barco

==================================================
6. CONTROL DE INVENTARIO
==================================================

Para activos tipo inventario:

- permitir cantidad
- permitir reducir cantidad si se usa o pierde
- registrar movimientos:
  - asignado
  - movido
  - dañado
  - eliminado
