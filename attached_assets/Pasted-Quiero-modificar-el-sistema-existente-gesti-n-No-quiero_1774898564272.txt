Quiero modificar el sistema existente “gestión”. No quiero una app nueva.

OBJETIVO
Cuando en “Nueva Transacción” se seleccione la cuenta:
- 2500 - Deferred Booking Deposits

el formulario debe activar un flujo especial para depósitos de reservas futuras.

Ese flujo debe permitir capturar toda la información del booking desde el inicio, para evitar repetir tareas después y para que el sistema pueda convertir automáticamente ese depósito en ingreso de renta del bote cuando llegue o pase la fecha del booking.

3. CUENTA POR COBRAR AUTOMÁTICA
==================================================

Cuando se registre un depósito en Deferred Booking Deposits, el sistema debe calcular automáticamente el saldo pendiente del booking:

saldo_pendiente = monto_total_booking - monto_depositado

Si el saldo pendiente es mayor que 0:
- crear automáticamente una cuenta por cobrar para la fecha del booking
- vincularla al cliente
- vincularla al bote
- vincularla al depósito original

CUENTA SUGERIDA
- Accounts Receivable / Cuentas por Cobrar

DATOS DE ESA CUENTA POR COBRAR
- cliente
- bote
- fecha del booking
- saldo pendiente
- horas rentadas
- referencia del depósito
- estado: pendiente

==================================================
4. AUTOMATIZACIÓN CUANDO EL BOOKING YA PASÓ
==================================================

Cuando llegue la fecha del booking o cuando el booking sea marcado como realizado/completado, el sistema debe poder hacer automáticamente la reclasificación contable necesaria.

OBJETIVO
Convertir el depósito y el saldo pendiente en ingreso real del bote rentado.

LÓGICA CONTABLE ESPERADA

A. AL MOMENTO DEL DEPÓSITO
- Debit: Cash / Banco
- Credit: Deferred Booking Deposits

B. SI HAY SALDO PENDIENTE
- crear cuenta por cobrar por el saldo

C. CUANDO EL BOOKING SE REALIZA
mover el depósito a ingreso real:
- Debit: Deferred Booking Deposits
- Credit: Booking Revenue

y si el saldo pendiente fue cobrado:
- Debit: Cash / Banco
- Credit: Accounts Receivable

o si todavía no se ha cobrado:
- mantener cuenta por cobrar abierta hasta pago

OBJETIVO

7. FLUJO RECOMENDADO
==================================================

Quiero este flujo:

1. Crear nueva transacción
2. Seleccionar cuenta: 2500 - Deferred Booking Deposits
3. El sistema abre campos especiales de booking
4. Ingreso:
   - nombre del cliente
   - fecha del booking
   - monto total del booking
   - depósito recibido
   - bote
   - horas rentadas
5. Guardar
6. El sistema:
   - registra el depósito en Deferred Booking Deposits
   - crea cuenta por cobrar por el saldo pendiente si aplica
   - guarda toda la relación con el bote y cliente
7. Cuando el booking pase o se complete:
   - aplica automáticamente el depósito a ingreso
   - genera ingreso por renta del bote
   - mantiene o cierra cuenta por cobrar según cobro real
