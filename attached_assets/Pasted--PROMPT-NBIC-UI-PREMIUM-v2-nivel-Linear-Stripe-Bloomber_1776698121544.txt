# PROMPT — NBIC UI PREMIUM v2 (nivel Linear + Stripe + Bloomberg Terminal)

## Contexto

La v1 funcional del Nadaki Business Intelligence Center ya está desplegada en /reports.html. Ahora elevamos el NBIC a nivel de producto SaaS premium — el estándar visual de Linear, Stripe Dashboard, Vercel, y Bloomberg Terminal. Este dashboard tiene que verse como algo por lo que alguien pagaría $200/mes en una suscripción B2B.

No es un rediseño cosmético. Es una reconstrucción de la capa de presentación con sistema de diseño propio, tokens, componentes robustos y microinteracciones.

Regla crítica: NO romper la v1 funcional. Trabaja de forma incremental. Los endpoints y la lógica de data siguen igual. Cambia solo la capa de presentación.

## Filosofía de diseño (no negociable)

Principio rector: densidad de información alta + jerarquía tipográfica impecable + quietud visual. El operador debe poder escanear 30 KPIs en 2 segundos sin sentirse abrumado.

Inspiración exacta:
- Linear — navegación, command palette, micro-animaciones, paleta monocromática
- Stripe Dashboard — tablas densas, KPI cards, data-ink ratio
- Vercel/Planetscale — dark mode técnico, uso de mono para números
- Bloomberg Terminal — densidad de información, color reservado solo para señal

Lo que NO queremos:
- Gradientes arcoíris, sombras exageradas, iconos decorativos
- Temática playera/náutica (anclas, olas, barcos)
- Emojis en UI, ilustraciones, empty states con dibujitos
- Border-radius grandes (nada > 8px excepto modales)
- Espaciado generoso tipo landing page — esto es un terminal operativo

## Reglas de oro
1. Data-ink ratio máximo. Cada pixel sirve.
2. Color solo como señal. Monocromático con 3 acentos estratégicos > lleno de colores.
3. Tipografía hace el 60% del trabajo. Inter + JetBrains Mono con escala disciplinada.
4. Animaciones invisibles. Si se notan, están mal.
5. Densidad > espaciado generoso. Esto es un terminal.
6. Nunca spinner central. Skeletons siempre.
7. Números en mono tabular. Siempre. Sin excepción.
8. Light mode diseñado conscientemente, NO un dark invertido.
9. Si dudas entre dos opciones visuales, elige la más sobria.
10. Tokens como fuente única de verdad. NUNCA hardcodear colores o spacing.
